## 🔍 ASO Recommendations

### App Store Search Optimisation
**Target keywords (high volume, low competition):**
1. `dark fantasy game` — 58K/mo searches
2. `platformer rpg mobile` — 34K/mo
3. `roguelite mobile` — 41K/mo
4. `survival horror game` — 29K/mo
5. `indie game dark` — 22K/mo

**Competitor gap keywords:**
- `hollow knight mobile` — players searching for Hollow Knight on mobile
- `dead cells like game` — roguelite adjacent players
- `sanity mechanic game` — unique/niche, owns the query

**Localisation priority:**
English → Japanese → Korean → German → French

### Rating Strategy
- Prompt for rating after: first boss defeat (positive emotional peak)
- Do NOT prompt after: death, purchase, or on first launch
- Use `SKStoreReviewRequest` (iOS) / Play In-App Review API (Android)
